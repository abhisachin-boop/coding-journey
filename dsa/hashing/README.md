# Hashing

Hashing lets us store and retrieve values efficiently using a hash table. In Python, the main tools are `dict` and `set`.

## Common patterns

- Frequency counting → `dict`
- Fast lookup → `dict` / `set`
- Duplicate detection → `set`
- Two Sum → store previously seen values in a dictionary

## Typical complexity

Average-case lookup, insertion and deletion are **O(1)** for Python dictionaries and sets.
