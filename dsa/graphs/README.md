# Graphs

A graph consists of **vertices (nodes)** connected by **edges**.

## Common representations

- Adjacency list — memory efficient for sparse graphs
- Adjacency matrix — simple, but uses O(V²) space

## Traversals

- **BFS (Breadth-First Search):** uses a queue
- **DFS (Depth-First Search):** uses recursion or a stack

```text
A --- B
|     |
C --- D
```
