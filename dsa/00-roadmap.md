## Practice Method

For each problem:

1. Understand the problem.
2. Write a simple solution.
3. Analyze time and space complexity.
4. Improve the solution when possible.
5. Add a small test case.

## Goal

Build strong problem-solving skills through consistent practice and clear explanations.
