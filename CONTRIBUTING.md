# 🤝 Contributing to Coding Journey

Thanks for checking out this repository.

This project is primarily a personal learning repository, but useful improvements and suggestions are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your change.
3. Keep code simple and beginner-friendly.
4. Add a short explanation when introducing a new concept.
5. Test your changes before opening a pull request.

## Good Contributions

- Fixing bugs or incorrect explanations
- Improving documentation
- Adding clear examples
- Adding small, well-documented practice problems
- Improving project structure

## Commit Style

Use clear commit messages, for example:

```text
feat: add binary search practice
fix: correct linked list example
 docs: improve DSA roadmap
```

## Code Style

Prefer readable code over clever code. Keep examples focused on the concept being learned.
